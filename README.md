# Kanban Task Manager

A Kanban-style task management app built with React and TypeScript.

## 🔗 Live Demo
[https://kanban-task-manager-murex.vercel.app/]


## ✨ Features
- Create multiple boards and tasks
- Inline editing — click any field to edit directly
- Task status tracking — Started, In-Progress, Done
- Priority levels — High, Medium, Low
- Task Border color changes based on task status
- Dynamic stats bar — total, started, in-progress, done
- Local storage persistence — data survives page refresh
- Toast notifications for every action
- Fully responsive design

## 🛠️ Tech Stack
- React 18
- TypeScript
- React Hot Toast
- Vite
- CSS

## 🚀 Run Locally
git clone https://github.com/VijayDhannarapu/kanban-task-manager
cd kanban-task-manager
npm install
npm run dev
